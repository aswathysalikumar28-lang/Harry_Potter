# ⚡ Hogwarts House Points Tracker

A Harry Potter-themed web application built with Flask and Groq AI (LLaMA 3.3), featuring multiple interactive pages set in the wizarding world.

---

## 🏰 Features

### 🏠 Home — House Points Tracker
- Add tasks and assign them to a Hogwarts house
- Complete tasks to earn points — Professor Dumbledore (AI) awards points with a witty reason
- Live leaderboard showing all 4 house point totals
- Points saved permanently with SQLite database

### 🎩 Sorting Hat
- Enter your name and get sorted into a Hogwarts house
- Powered by Groq LLaMA AI in the voice of the Sorting Hat

### 📖 Spell Book
- Browse 24 iconic Harry Potter spells
- Search spells by name or description

### 🏆 Hall of Fame
- Podium showing all 4 houses ranked by points
- Full history of completed tasks with AI-generated reasons

### 🗺️ Marauder's Map
- Animated interactive map of Hogwarts
- Characters appear and move around the castle in real time

### 🧪 Potions Class
- Choose a potion recipe and brew it by adding ingredients in the correct order
- 4 recipes: Polyjuice Potion, Felix Felicis, Veritaserum, Wolfsbane Potion

### 🦌 Patronus Generator
- Describe your happiest memory
- AI generates your unique Patronus animal with a magical description

### 📰 Daily Prophet
- AI-generated fictional wizarding world news
- Styled as a real newspaper front page

### 🏐 Quidditch Score Tracker
- Track scores for any two Hogwarts teams
- Goals (+10) and Golden Snitch (+150) buttons
- Match ends automatically when Snitch is caught

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| Python Flask | Backend web framework |
| Groq API (LLaMA 3.3 70B) | AI features (Sorting Hat, Points, Patronus, Prophet) |
| SQLite | Persistent database for points and tasks |
| HTML/CSS/JavaScript | Frontend (all CSS embedded in HTML) |
| Cinzel & Lato fonts | Typography |
